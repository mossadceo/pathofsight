# Third-party notices

Path Of Sight includes code and embedded reference data from [Sikaka/POE2Radar](https://github.com/Sikaka/POE2Radar), pinned at revision `a23cdb6bf8dfb59dee53008a86439f05b24e3a57`. The imported source is in `vendor/POE2Radar.Core`; its MIT license is preserved in `vendor/POE2Radar.LICENSE` and included with the binary distribution.

The self-contained Windows distribution includes Microsoft .NET, ASP.NET Core, and Windows Desktop runtimes. Their licenses and notices are supplied in the release package. Path Of Sight does not distribute the game client.

Local reader change for profile filters: the restricted `pointsOfInterestOnly` branch in `Poe2Live.Entities` now returns NPC and non-breakable chests, and reads chest opened state. It includes living, non-friendly Magic/Rare/Unique monsters through a shared visibility predicate. The `SleepingEntities` scan returns distant monsters with readable rarity and position, plus specifically recognized stationary POIs with readable positions (Shrines, Checkpoints, Waypoints, Ritual rune objects, and Expedition2 encounters). Awake Ritual rune objects are included even without minimap icons. Normal monsters are excluded from the radar. The reader still excludes players and does not use the full loot/mod/item-identity path. NPC tracking and filter classification remain in the application layer. No memory signatures or offsets were changed for this feature.
