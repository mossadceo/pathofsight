# Path Of Sight

Карта Path of Exile 2 с переходами, аренами, квестовыми ориентирами, waypoint, checkpoint и доступными шрайнами. Windows x64, оконный или безрамочный режим игры. Готовая сборка включает .NET; Linux не поддерживается.

**Статус: сборка для проверки, с частичной проверкой на живой PoE2.** В Scorched Farmlands работают чтение карты, ближайших объектов и оверлей по Tab. Полный критерий готовности (три зоны по два экземпляра, смена зон, перезапуск клиента, шрайны) ещё не пройден. Подробности — в `VALIDATION.md`.

## Запуск

1. Скачайте `pathofsight-win-x64.zip` со страницы [релизов](https://github.com/mossadceo/pathofsight/releases) и распакуйте в отдельную папку.
2. Запустите `pathofsight.exe` двойным кликом или из PowerShell / Windows Terminal. Сразу открывается двухколоночное меню: белый глаз с приглушённо-красным зрачком слева и две команды справа. Заголовок Functions и подсказки клавиш выделены красным. Логотип отображается слева при обычной высоте терминала; при сильном уменьшении окна сведения скрываются, а команды остаются доступны. Размер окна не меняется автоматически; устанавливать .NET не требуется.
3. Запустите PoE2, войдите персонажем в локацию и нажмите **1 — Подключиться к игре**. Пока команда не выбрана, pathofsight не читает игру.
4. Нажмите **2 — Открыть веб-карту**, чтобы открыть её в браузере. Браузер автоматически не запускается. В игре нажмите **Tab**: оверлей появляется при открытой карте, пока окно PoE2 активно.

Терминал можно свернуть. **Q — Выход**, Ctrl+C или закрытие окна терминала завершают работу. Если отображается сообщение о недостаточных правах, запустите pathofsight от имени администратора. Приложение не запрашивает повышение прав автоматически.

Демонстрационный режим доступен только через аргумент `--demo`; он всегда явно подписан и не подтверждает совместимость с игрой. Маршрут и настройки пока выбираются в веб-карте.

## Управление

- Колесо мыши меняет масштаб, перетаскивание двигает отдельную карту. **Вся карта** подбирает масштаб; **К персонажу** включает слежение.
- Нажмите цель в списке или её значок, чтобы построить маршрут. **Сбросить маршрут** снимает выбор. Для непроходимой цели выводится «Путь не найден».
- Контурный значок — ориентир, найденный по геометрии. Сплошной — координаты игрового объекта. «Запомнен» означает, что неподвижный объект уже наблюдался в этом экземпляре, но сейчас отсутствует в читаемом списке.
- Фильтры категорий, размер значков, подписи и прозрачность общие для карты и оверлея. По умолчанию обычные монстры и сундуки не отображаются.
- Оверлей считывает позицию персонажа отдельно от обновления POI, примерно каждые 16 мс, чтобы уменьшить рывки при движении. Трещины и разломы Abyss не выводятся в POI; входы Abyss остаются.
- Через **⋯** можно переименовать или скрыть тип отметки. Настройка относится к соответствующему типу объекта в этой локации; **Показать все скрытые** отменяет скрытие.
- При несовпадении с игровой картой используйте **Совмещение оверлея**. Это не влияет на координаты отдельной карты.

## Данные и ограничения

Приложение читает память клиента. Оно не изменяет файлы игры, не записывает в процесс и не отправляет нажатия клавиш. PoeRedux и ExileCore для запуска не нужны. Внешних запросов цен, телеметрии и автоматического обновления нет. Локальный сервер слушает только `127.0.0.1` на свободном порту.

Ориентиры кампании взяты из справочника POE2Radar указанной ревизии. Отсутствие отметки не означает отсутствие объекта. Не все переходы однозначно определяются геометрией; её центр может отличаться от кликабельной точки. Случайные объекты могут стать доступны только при приближении. Waypoint и checkpoint — разные категории. Маршрут по проходимой поверхности не учитывает все состояния дверей, событий и способностей персонажа.

Upstream-файлы смещений относятся к обновлению от 2026-09-05; смещение списка активных состояний исправлено по живому клиенту 2026-09-24. Проверен Steam EXE с SHA-256, начинающимся на `DC3B3F1BEDBF664A`; у этого файла нет номера версии. После обновления игры чтение может потребовать исправлений. При некорректной геометрии или координатах pathofsight скрывает карту; сообщения «Нет данных персонажа» могут означать как загрузку, так и несовместимость.

Настройки и журнал находятся в `%LOCALAPPDATA%\pathofsight`. Адрес активной карты записан в `server-url.txt`; журнал ограничен по размеру. Журнал не отправляется в сеть. Меню веб-карты **О приложении → Диагностика** показывает версию и состояние без имени персонажа.

## Сборка и проверка

В PowerShell из корня проекта:

```powershell
./build.ps1
```

Скрипт устанавливает .NET SDK 10.0.401 локально в `.tools`, собирает проект, запускает проверки и создаёт `dist/pathofsight-win-x64.zip` с SHA-256. Исходники: `src/pathofsight`; зафиксированное ядро: `vendor/POE2Radar.Core`. Системный SDK не требуется.

Параметры для испытаний:

```text
pathofsight.exe --demo
pathofsight.exe --port 17877 --data-dir artifacts/qa-data
pathofsight.exe --render-demo artifacts/map.png
pathofsight.exe --render-demo artifacts/map-150.png --dpi150
```

`--port` задаёт локальный порт вместо автоматического, `--data-dir` изолирует тестовые настройки. Рендеры проверяют слой WPF при 96/144 DPI, не меняя масштаб Windows.

Основа — [POE2Radar](https://github.com/Sikaka/POE2Radar), MIT. Подробности в `THIRD-PARTY-NOTICES.md`.
