# Compatibility and validation

Path Of Sight is an early Windows x64 release. Its automated checks cover map data, landmark handling, pathfinding, settings, local API protections, and terminal layout. A live Path of Exile 2 client has been used to verify terrain reading, nearby landmarks, routing to a checkpoint, and the Tab-map overlay in one campaign area.

Compatibility across game versions, zones, display scales, and all landmark types is not yet established. An update to Path of Exile 2 may require changes to memory signatures or offsets. Geometric landmarks are approximate until confirmed by a game object.

The repository includes an anonymized terrain fixture at `tests/pathofsight.Tests/fixtures/scorched-entry.json` for pathfinding checks. It contains terrain cells and relative positions, without account, character, or process-address data.

2026-09-26: A live Digsite waystone instance (`MapExcavation`) exposed a `BossArena_Forge_PCR_01` terrain tile. Follow-up: a screenshot showed that this terrain marker was visibly outside the arena. Read-only inspection of a fresh Digsite instance found a sleeping `BossLeagueContentMarkerMain` entity with a position at grid ~752.5,1743.5 before the boss appeared. In Clearfell, a sleeping `BossRoomMinimapIcon` position (~1150.5,789.5) was close to the known boss terrain landmark (~1138.5,782), supporting the position field interpretation. The app now prefers these preloaded markers in waystone maps. Visual alignment of the rebuilt app in a live Digsite instance remains to be confirmed.

Automatic routing now selects a boss only in `Map…` areas. The selection prefers an active boss, then a preloaded spawn marker, then an arena landmark; manual selection can temporarily override it. Automated checks cover the map-only gate and target priority. A complete automatic route from the entrance to a Digsite boss has not yet been observed live; disconnected terrain still yields an honest no-path status.

Long-distance routing regression: on a connected 800×800 synthetic map with a distant opening in a wall, the former 250,000-node limit found a route only near the boss; the new map-boss budget finds the route from the entrance. Campaign boss searches retain the old budget. A read-only check in a live `MapWillow` instance found a preloaded boss marker and a nine-point route from the observed player position in 65 ms with the old limit; this map did not reproduce the delayed-route issue. The affected layouts still need a live entrance capture to distinguish search exhaustion from disconnected terrain or a boss marker that appears only nearby.
